# FABRINCANDO LOJA DE FÁBRICA
Loja oficial direto da fábrica para sua casa - www.fabrincandoideias.com.br

## 🚀 Como está agora
- **Frontend completo**: banner rotativo a cada 4s, categorias, busca, lightbox com temas
- **6 produtos iniciais**: 6501 Bombeiros, 7102 Sereias, 9609 Dinos, 5250 Galinha Azulzinha, 0688 Cercado Rosa, 5441 Pizzaria
- **Cálculo editável**: desconto livre por produto (30%/40%/42%/50%/55% OFF) - não força mais 1.71 fixo
- **Preço com vírgula**: aceita 110,88 com centavos
- **Salvamento automático**: chave fixa fabrincando_fixo_v1

## 📦 Arquivos
- `index.html` = loja completa final (essa é a que vai pro ar)
- `supabase_schema.sql` = banco de dados Supabase
- `supabase_env_template.txt` = modelo de chaves
